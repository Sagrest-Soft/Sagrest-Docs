# Opzioni

&#x20;Attraverso questa sezione è possibile configurare le impostazioni interne del server e le informazioni della sagra.

## Modifica delle impostazioni[​](#modifica-delle-impostazioni "Link diretto a Modifica delle impostazioni")

Per modificare le impostazioni, modificare il campo desiderato nella colonna `Valore` e premere il pulsante `Modifica` per confermare le modifiche.<br />

***Importante***: alcune impostazioni possono influenzare il funzionamento del programma. Modificare solo le impostazioni di cui si è sicuri.
