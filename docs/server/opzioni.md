# Opzioni

![](/assets/images/options-a511564a37e04d61653415030856f49b.png) Attraverso questa sezione è possibile configurare le impostazioni interne del server e le informazioni della sagra.

## Modifica delle impostazioni[​](#modifica-delle-impostazioni "Link diretto a Modifica delle impostazioni")

Per modificare le impostazioni, modificare il campo desiderato nella colonna `Valore` e premere il pulsante `Modifica` per confermare le modifiche.<br />![](/assets/images/options_update-c2c373f38f152230a56c57f1a72fb51b.gif)

***Importante***: alcune impostazioni possono influenzare il funzionamento del programma. Modificare solo le impostazioni di cui si è sicuri.
